# Blood Bank Management System

A simple blood bank management system made using Python and MySQL.

## Features

* Donate blood and store donor details
* Receive blood and store patient details
* Check blood availability
* Display available blood units
* Update blood inventory after donation or receiving blood

## Technologies Used

* Python
* MySQL

## How to Run

1. Install Python and MySQL.
2. Install the MySQL connector:

```bash
pip install mysql-connector-python
```

3. Create the required database and tables in MySQL.
4. Update the database connection details in `main.py`.
5. Run:

```bash
python main.py
```

## Note

This is a beginner-level project I made while learning Python and MySQL.
